# Host conformance transcripts

Each `*.jsonl` file is one transcript of the host protocol
([SPEC.md §9](../../SPEC.md#9-host-protocol)) between a driver and a host
running the **conformance handler** (§9.6). Every SDK runs all of them.

```bash
python3 spec/host/run.py --host "<command that starts your conformance host>"
```

`run.py` appends `kavach-host` to the command, plays every transcript, and
exits non-zero if any fails. It needs Python 3.10+ and nothing else. Pass
`--pass-env NAME` for variables your runtime needs (e.g. `PYTHONPATH`,
`NODE_PATH`); the host otherwise gets only `PATH`, `HOME` and the variables the
transcript names.

## Format

One JSON object per line:

| Entry | Meaning |
| --- | --- |
| `{"comment": "..."}` | Ignored. Each transcript starts with one saying what it tests. |
| `{"env": {"NAME": "value"}}` | Only as the first non-comment line: start the host with these environment variables. |
| `{"send": {...}}` | Write this driver message to the host. |
| `{"expect": {...}}` | The host's next message must equal this, compared as JSON values, ignoring `ready.sdk`, `ready.environment` and `done.detail`. A line on the host's standard output that is not JSON fails the transcript. |
| `{"expect_exit": 0}` | Close the host's input; it must exit with this status within 5 seconds and write nothing more. |

Bytes are base64, as on the wire.

## Changing transcripts

The transcripts are generated by [`gen.py`](gen.py). Edit the cases there and
run `python3 spec/host/gen.py`; never edit the `.jsonl` files by hand. A new
transcript is a change to the contract every SDK must meet, so it goes in the
same change as the SPEC.md text it tests.
