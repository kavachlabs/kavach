name: property-based-testing
description: >
  Use when writing tests for code with invariants, state machines, parsers or financial calculations, or when example-based tests miss edge cases. Generates inputs with Hypothesis, fast-check or gopter and shrinks failures.
---

# property-based-testing

Identify properties that must hold for all inputs, write generators, and let the framework find and shrink counterexamples.
